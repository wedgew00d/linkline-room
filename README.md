- 構成：index.html（Space版の書き出し単一ファイル）＋ assets/char/（キャラ画像11点）
- ←→：移動 ／ Space・Z：ジャンプ ／ 調べる：状態変化型インタラクト6か所（本棚／ベッドで休む／コンソール表示切替／シャワー／ロッカー／ドア）
- スマホ横画面では、右側にメッセージとボタンが並ぶ2カラムレイアウトになります
- ルートに残っている旧ファイル（room_pano*.jpg、run8_*.png など）は前バージョンの素材で、現行版では使いません

GitHub Pages でそのまま遊べます。
