# LINKLINE — プライベートルーム（探索）

LINKLINE社のプライベートルームを、キャラBで歩いて調べる2Dスクロール探索ページ。

- ←→：移動 ／ Z・スペース：ジャンプ ／ ↑・E：調べる・操作する ／ R：最初の位置へ
- スマホでは画面のボタン（←→／調べる／跳ぶ）でも操作できます
- 調べられる場所は12か所（ベッド／シャワーポッド／本棚／端末デスク／ソファ／窓／ミニバー／観葉植物／ドア／ワードローブ／絵画／ローテーブル）
- うち5か所は状態変化型：ベッドで横になる／シャワーのオン・オフ／端末の表示切替（通常→航路→消灯）／ドアの開閉／ワードローブの開閉

GitHub Pages でそのまま遊べます。
